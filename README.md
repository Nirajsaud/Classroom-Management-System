# Pathshala - Student Management System

CS5054NI Advanced Programming Technologies - Group Coursework



## Tech Stack
- Java Servlets + JSP
- MySQL
- Apache Tomcat 10.1
- Maven
- Eclipse IDE
- CSS + JavaScript



## How to set up

### 1. Clone the repository
git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git

### 2. Import into Eclipse
- File → Import → Existing Maven Projects
- Browse to the cloned folder → Finish
- Right-click project → Maven → Update Project (Alt+F5)

### 3. Update your database credentials
Open:
src/main/java/com/islington/pathshala/util/DBConnection.java

Change to your local MySQL username and password.

### 4. Run on Tomcat
- Right-click project → Run As → Run on Server
- Choose Apache Tomcat 10.1
- Open browser → http://localhost:8080/Pathshala



## Default Admin Login
Email     admin@pathshala.com

Before starting work:

git checkout -b feature/your-name

Push your work:

Then open a Pull Request on GitHub to merge into main.
